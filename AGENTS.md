# Hongxiang Meng Portfolio

## Project Purpose

Build a professional personal portfolio website for Hongxiang Meng.

The website is primarily for:
- Job applications
- Professional personal branding
- Project presentation
- Future HEOR / RWE / healthcare analytics career development

The website language should be English.

## Professional Positioning

Primary positioning:

Clinical Pharmacology | HEOR & RWE | Data Analytics

The website should present Hongxiang as an early-career professional with a clinical pharmacy and clinical pharmacology background who is developing toward HEOR, Real-World Evidence, and healthcare data analytics.
